# M-11a validation (build environment, PostgreSQL 16.15)

These scripts were used to validate M-11a in the build environment before approval. Paths refer to
that workspace (`/home/claude/m11a`, staged migrations under `/mnt/user-data/uploads`); they are kept
as a record of exactly what was run, not as project tooling. The last full run (revision 4) is in
`results-rev4.txt`; `results-rev3.txt` is kept as the revision 3 record.

| Script                                  | What it checks                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `run_all.sh`                            | Runs everything below in order and writes `results-rev4.txt` (the record of the last full run)                                                                                                                                                                                                                                                                                                                                                                                                                |
| `rebuild.sh`                            | Fresh scratch database from the eight migrations in `prisma/migrations` plus `seed.sql` (two hospitals, admins, a lab test, a medicine, two rooms)                                                                                                                                                                                                                                                                                                                                                            |
| `behaviour_tests.py`                    | 120 rule checks (7 added in revision 4), each in its own rolled-back transaction with a simulated clock (`medcore_tax_clock()` replaced inside that transaction only)                                                                                                                                                                                                                                                                                                                                         |
| `commit_tests.sh`                       | Commit-time checks under a real `COMMIT`, on a throwaway database whose clock function is permanently simulated                                                                                                                                                                                                                                                                                                                                                                                               |
| `concurrency_tests.sh`                  | Six two-session races between a time-zone change and the first tax version or registration (READ COMMITTED, REPEATABLE READ, SERIALIZABLE); real clock, run before 23:50 IST                                                                                                                                                                                                                                                                                                                                  |
| `timing_tests.sh` (rev 3)               | What the time checks do not guarantee and what the row locks do: a commit stalled in a synchronous-replication wait after its commit-time check; the `SET CONSTRAINTS ALL IMMEDIATE` bypass; locking readers still see only final values; `idle_in_transaction_session_timeout`; no `transaction_timeout` on PostgreSQL 16; FK inserts not blocked; lock order without deadlock; a control without the writer locks. Test 1 changes `synchronous_standby_names` on the scratch cluster and always restores it |
| `lock_nowait_tests.sh` (rev 3)          | SQL rehearsal of T-MIG-TAX-011 (`FOR SHARE NOWAIT` from a second session), against revision 3 and against the control                                                                                                                                                                                                                                                                                                                                                                                         |
| `classification_race_tests.sh` (rev 4)  | Two-session races between assigning a classification (hospital default, lab test, medicine), adding a version and deactivating that classification, at READ COMMITTED, REPEATABLE READ and SERIALIZABLE; lock order against a locking reader; plain reads and FK inserts not blocked; SQL rehearsal of T-MIG-TAX-013; a control with revision 3's unlocked assignment check that reproduces the race                                                                                                          |
| `gstin_verification.py`                 | `medcore_gstin_valid()` against python-stdnum 2.2 and real GSTINs from published documents; mutation and random comparisons. Output: `gstin_verification-output.txt`                                                                                                                                                                                                                                                                                                                                          |
| `gstin_reference.md`                    | Accepted and refused GSTIN formats, sources and every test vector                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `rollback_checks.sh`                    | Atomicity (injected failure), re-apply refusal, manual reversal, reversal guard (configuration, later statutory rules, altered seed, lock-only)                                                                                                                                                                                                                                                                                                                                                               |
| `conform.js`                            | 198 comparisons between the proposed Prisma schema (via Prisma's own schema WebAssembly, engine c2990dca) and the migrated database: columns, types, nullability, defaults, keys, unique indexes, foreign keys and actions, enum values                                                                                                                                                                                                                                                                       |
| `dataq.sql`, `dataq_old.sql`, `dump.sh` | Row hashes and schema dumps used for before/after comparisons                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
